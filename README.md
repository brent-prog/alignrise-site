# AlignRISE Site

Clean Next.js/Vercel rebuild for the AlignRISE website.

## Source of truth

- AlignRISE brand guidelines
- Existing approved SVG logo assets from the prior AlignRISE repo
- Product positioning: business alignment system by 3P Solutions

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The app is a static-first Next.js App Router site built for Vercel.
