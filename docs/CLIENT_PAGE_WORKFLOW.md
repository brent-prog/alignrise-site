# AlignRISE master template v1 — operating workflow
The actual master is src/components/prospect/ProspectExperience.tsx and its existing prospect.css, ProspectNavigation, ProspectVideo, ScenarioCalculator and EmailAcceptance components. Hand & Stone is the reference fixture and remains the visual baseline. The template is code, not a description to recreate. Do not create separate HTML, routes, CSS or layouts for clients. Routine work changes client data and approved client-specific assets only; changes to the master require a separate approved version and regression review. Preserve the current v1 files for existing clients when developing v2.
1. Read prospect context and verify the offer, identity, branding, price, billing cadence, tax, commitment, cancellation, outcome claims and CTA. Never import another client's commercial conditions.
2. Branch from main. Add a unique slug record in src/content/prospect-pages.ts with templateVersion: "v1", status: "draft", following CLIENT_CONTENT_SCHEMA.md. Use official client logo only when verified; otherwise use the name fallback. Never include confidential details in this public repository.
3. If supplied, process approved video and poster per VIDEO_UPLOAD_PLAYBOOK.md. No video is fine; the existing hero adapts.
4. Push feature branch, open draft PR, inspect Vercel preview and confirm READY for exact commit. Review desktop and mobile visually and run npm run build, npm run lint, npm run test:proposals and existing CI. Check anchors, media, email, no overflow and existing Hand & Stone and Rob Cooper pages. Do not call a preview private unless authenticated.
5. Show Brent exact preview for approval. Resolve unknown commercial terms and assets before publication. On explicit approval change status to published, rerun checks and merge. Confirm production READY, domain and exact deep link. Never send to prospect without separate instruction.
6. For new functionality that cannot be expressed in the schema, stop and propose a separate template-version change. Do not create a workaround page.
