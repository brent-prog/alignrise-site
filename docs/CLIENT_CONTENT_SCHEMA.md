# Master v1 content schema
Source of truth: src/content/prospect-pages.ts. Client records are data, not presentation. Use templateVersion "v1". slug unique, status draft/published/archived, clientName, optional verified clientLogo {src,alt,sourceUrl}, eyebrow, title, greeting, intro, contactEmail, contactSubject, offerName. Use context and opportunities arrays (empty if omitted). Optional process and deliverables arrays; sectionOrder controls rendered sections, sectionLabels overrides navigation, sectionHeadings overrides headings, heroActions lists label and target (section ID without #). Unknown or disabled sections do not appear in navigation. extraSections provides id/title/paragraphs. NextStepLabel in code is nextStepLabel; default is email to discuss.
Subscription: subscription {price, cadence, regularPrice?, introductoryPeriod?, taxNote?, continuation, includes[]}. Cadence is the billing unit, e.g. week, month, quarter, year or custom text. Confirm currency CAD, tax and renewal/cancellation independently. Use note for commitment/conditions. No assessment, calculator or guarantee by default. Use the existing toolkit module only when appropriate; optional badge, durationLabel and factLabel customize its wording.
KickStart/custom: price, normalPrice, offerHeadline, note, terms as appropriate; do not inherit Hand & Stone terms. Existing legacy acceptance is specifically designed for the original KickStart contract and should only be reused for matching approved terms; new acceptance requirements need a separately reviewed module. For combined offers, review how the separate toolkit and subscription terms are expressed; never imply free access unless approved.
Explainer: no price necessary; use offerHeadline and a discussion CTA. Omit irrelevant modules via sectionOrder; keep a next step. Optional video {src,poster,heading?,caption?}; optional calculator is the existing appointment scenario only and requires verified assumptions. No synthetic client logos. See Takoda draft for subscription and Hand & Stone for legacy KickStart.
